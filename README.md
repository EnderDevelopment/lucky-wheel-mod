# Lucky Wheel Mod

A spinning wheel mod for Minecraft Bedrock Edition.

## Features

- 3D spinning wheel with colored segments
- Fixed arrow for smooth animation
- English UI with SPIN, ADD ITEM, REMOVE ITEM, and LAST WINNER buttons

## Requirements

- Minecraft Bedrock Edition 1.26.60
- Forge 1.26.60

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your Minecraft Bedrock Edition mods folder.
3. Launch Minecraft Bedrock Edition and enable the mod in the settings.

## Usage

1. Place the wheel block in the world.
2. Right-click the wheel block to open the UI.
3. Click the SPIN button to spin the wheel.
4. Click the ADD ITEM button to add items to the wheel.
5. Click the REMOVE ITEM button to remove items from the wheel.
6. Click the LAST WINNER button to see the last winner.

The mod does not have a configuration file.
